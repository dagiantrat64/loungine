Asset format:
Assets are not loaded at runtime as their initial format and are instead compiled into a format into what is essentially
a large binary blob.
The asset format is composed of a header, information table with each entry corresponding to an asset, and the assets
themselves which are represented by an array of vertex data (as described by Vertex type defined in src/vertex.h). The
information stored within can be visualized as such:

|Header: |Entry #1:   |Entry #2:   |...|Entry #n:   |Asset #1:   |Asset #2:   |...|Asset #n:   |EOF
|n assets|offset, size|offset, size|   |offset, size|Vertex[size]|Vertex[size]|   |Vertex[size]|
                                                    ^offset from         ^size     ^Vertex type from src/vertex.h
                                                    Entry #1             from
                                                                         Entry #2
